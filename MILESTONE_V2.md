# Driftlock V2 — Evidence Assurance & Appeals

Driftlock's V1 covenant protects one public promise at one frozen URL. This V2 source adds a frozen multi-source evidence policy, bounded rendered-text commitments, independent judgment over a fixed incident, one bonded appeal and settlement only after appeal finality. The purpose remains **stake a public promise; prove when it changes**.

The implementation was merged to `main` by PR #4 at `d83575698c1c3fa78c73c9b5adc1b3094d14b25a`, from V1 baseline `4987c25a726e2ff8db0fb5bf8f76daa750c970bb`. See [`docs/milestone-v2/V1_V2_MATRIX.md`](docs/milestone-v2/V1_V2_MATRIX.md) for code and tests, and [`docs/milestone-v2/LIVE_VERIFICATION.md`](docs/milestone-v2/LIVE_VERIFICATION.md) for deployment and lifecycle evidence. Corrected V2 Registry, Inspector and Judge contracts are finalized and bound on Studionet; the active local frontend manifest and production site point to them. Recorded live evidence includes a V2 multi-source `dl-5`/`dc-5` source breach, bonded appeal, upheld breach judgment, settlement and finalized withdrawal, plus baseline and unchanged-source appeal runs. Chrome QA covered wallet account changes, refresh recovery, wrong-network handling and transaction signing; explicit transaction rejection remains untested. Publisher independence is not established. See the live record for receipts, outstanding test escrow and exact evidence limits.
